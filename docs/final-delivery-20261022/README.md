# ArcProof final-delivery materials

Prepared 2026-10-22. These are reviewable materials, not a mainnet, publication or submission receipt. The baseline is [`cd579e5`](https://github.com/peterpeter228/arcproof/tree/cd579e567457ff8acf0fe041a5cff3df07c344c0); the engineering candidate is being changed separately and must receive its own version-bound results.

ArcProof links a fixed USDC invoice to a one-time atomic payment and a receipt that can be checked independently against Arc. This unaudited prototype has a 1 USDC per-invoice cap, no escrow, no refund mechanism and no autonomous spending.
