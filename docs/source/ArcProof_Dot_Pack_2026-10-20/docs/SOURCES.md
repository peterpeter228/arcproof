## 来源冲突处理

Arc 第一期、第二期分别存证。二级站点转载相同文字不等于两份独立主办承诺。提取不到正文不等于无资格限制；标Global不等于本人无条件可领。

Solana提案、总览、更新公告和实时RPC属于不同证据类型。旧页面仍显示testnet时，应列出与较新主网公告的差异；实际计算始终依赖当前集群查询。本次RPC读取没有成功，未声称亲自测得2026-10-20实时押金值。

所有动态提交数只代表访问快照。无可比、经校准的历史结果时，不输出个人获奖概率。概率表、服务价格、工作量和转化阈值全部属于情景或本次试验设计。
