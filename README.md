# ArcProof

Fixed USDC payment requests and independently verifiable payment receipts on Arc.

## Current status

This repository is in planning and eligibility verification (Gate G0). No application or funds-handling contract has been implemented, audited, or deployed.

Implementation must wait until all G0 eligibility, submission, account access, and service constraints have been verified. Project documentation and an execution plan are being prepared.

Do not send funds to any address or contract on the basis of this repository.
